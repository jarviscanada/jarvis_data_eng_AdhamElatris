# COBOL Student Registration System

## Overview
This project is a **COBOL-based Student Registration System** designed to run on a mainframe environment.  
It provides core functionalities for managing student records, including:
- Adding new student records
- Updating existing records
- Deleting records
- Querying student information

The system also supports generating detailed course-based reports.

## Features
- **VSAM Integration**: Efficient indexed storage of student data using VSAM files.
- **File Conversion**: Transformation of sequential files into VSAM format.
- **Modular Programs**: Designed to handle complex queries by student ID and enrollment date.
- **Batch Processing**: Built for enterprise batch environments to manage large volumes of data.

## Technical Highlights
- Developed in **COBOL** with a focus on modular design and maintainability.
- Extensive use of **file handling** (Sequential, Indexed, and Relative Files).
- Implementation of **control structures** (decisions, loops, and tables).
- **Data validation** to ensure consistency and accuracy.
- Reporting features to group students by courses.

## How It Works
1. Student records are stored in **VSAM files** for fast and reliable access.
2. Users can perform **CRUD operations** (Create, Read, Update, Delete).
3. The system supports **querying by ID or enrollment date**.
4. Reports can be generated and grouped by course.
